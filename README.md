# Simfoni Waktu

Simfoni Waktu: Ruang VIP Geng Sekolah — interactive VIP lounge web experience.

This repository contains a lightweight, mobile-friendly single-page site themed as a VIP lounge for friends (Azriel, Fikri, Abid, Arfa). The site includes a neon cyberpunk visual style, a lightweight canvas "matrix" background, and a simulated music visualizer.

Files:
- index.html — full site (HTML/CSS/JS) ready to open in the browser.
